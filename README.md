SkillCraft Technology Internship Task 04

Description
This is created as part of my 4th internship task. It monitors keyboard inputs and logs them into a local text file. This project was developed strictly for educational and security awareness purposes.

Features
Logs standard alphanumeric characters seamlessly.
Formats special keys (Space, Enter, etc.) for readability.
Includes a safe exit mechanism (Press 'Esc' to stop).
Technologies Used
Python 3
pynput library
How to Run
Install dependencies: pip install pynput
Run the script: python keylogger.py
View logs in key_log.txt
